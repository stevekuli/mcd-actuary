# 🍟 麦门精算师（McMen Actuary）

> 输入预算和想吃的东西，AI 自动领光所有券、试算全部组合，告诉你**怎么点麦当劳最省**。
> 内置「每日麦麦播报」：每天早上把今日活动、新上的券、积分状态浓缩成一条简报。

基于 [麦当劳中国官方 MCP 服务](https://github.com/M-China/mcd-mcp-server) 开发的参赛 Skill —— **2026 麦当劳程序员创意开发大赛**。

## ✨ 它能做什么

| 模式 | 你说 | 它做 |
|---|---|---|

## 🚀 快速开始

### 1. 申请麦当劳 MCP Token

前往 [open.mcd.cn/mcp](https://open.mcd.cn/mcp) → 手机号登录 → 右上角「控制台」→「激活」→ 复制 Token。

### 2. 配置 MCP 连接器（以 WorkBuddy 为例）

左侧边栏【专家·技能·连接器】→【连接器】→ 右上角【自定义连接器】→【配置MCP】，填入：

```json
{
  "mcpServers": {
    "mcd-mcp": {
      "type": "streamablehttp",
      "url": "https://mcp.mcd.cn",
      "headers": {
        "Authorization": "Bearer YOUR_MCP_TOKEN"
      }
    }
  }
}
```

> ⚠️ 把 `YOUR_MCP_TOKEN` 替换成你的真实 Token，保存并启用。
> 其他客户端（Cursor / Cherry Studio / Trae / VSCode 等）配置方式相同，见 [官方接入指南](https://github.com/M-China/mcd-mcp-server)。

### 3. 安装本 Skill

把本仓库的 `SKILL.md` 与 `references/` 目录复制到你的技能目录：

- **WorkBuddy**：`~/.workbuddy/skills/mcmen-actuary/`
- **Claude Code / 其他 Agent**：放入对应 skills 目录即可（SKILL.md 为通用格式，不绑定特定框架）

### 4. 开聊

```
你：30 块预算，一个人，想吃堡，到店自取，我在珠江新城
精算师：🏆 最优方案（实付 ¥23.50）……
```

## 📊 真实实测战果（2026-10-09）

AI 实测：**三张 ¥9.9 券组合，原价 ¥49.00 → 实付 ¥29.70，立省 ¥19.30（39.4%）**

| 方案 | 原价 | 券后实付 | 立省 | 降幅 |
|---|---|---|---|---|
| 麦旋风任选（用券） | ¥14.00 | **¥9.90** | ¥4.10 | 29% |
| 薯薯任选（用券） | ¥16.00 | **¥9.90** | ¥6.10 | 38% |
| 9.9元中杯冰美式（用券） | ¥19.00 | **¥9.90** | ¥9.10 | 48% |

## 🧠 精算逻辑（为什么它算的比你快）

1. **券先领光**：`auto-bind-coupons` 全量领券，建立可用券池（门槛/面额/适用品类）
2. **套餐优先**：必吃项先查套餐形态——套餐价通常比单点便宜 5-15 元
3. **门槛反凑**：对"满30减10"这类券，反向计算缺口，用最接近缺口的单品补齐（甜筒、小薯是经典凑单品）
4. **活动叠加**：对照当日活动日历，会员日特价、第二件半价一并计入
5. **批量试算**：≤8 个候选组合走 `calculate-price` 实算券后价，按实付升序输出 Top 3

详细策略见 [references/combo-strategy.md](references/combo-strategy.md)。
